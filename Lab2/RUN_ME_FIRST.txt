LAB 2 — START HERE — v3 CONTINUOUS 3-TRIAL MUJOCO SESSION

Extract the ZIP into a NEW folder and open a terminal inside Lab2/.

  python -m pip install -r requirements.txt
  python -m pytest -q
  python preflight.py --trials 3 --seed 13
  python run_lab2.py --check-scene --trials 3 --seed 13
  python run_lab2.py --trials 3 --seed 13
  python run_lab2.py --trials 3 --seed 13 --record

The last command produces ONE video for all three trials:
  outputs/all_trials_continuous.mp4

The MuJoCo environment and viewer stay alive throughout all trials.
Between trials, ONLY the single block is scripted back to the table
so the next trial can begin. It is NOT a physical robot reverse transfer.
The block's left shelf placement and right shelf placement are each
randomized horizontally (world X) across three bins for --trials 3.
Changing --seed produces a different, reproducible set of sampled targets.

The source shelf geometry is UNMODIFIED. The v2 side-regrasp lift-before-
retreat / shelf-contact fix is included. No hardware commands are present.

LIMITATIONS: MuJoCo was unavailable in the build environment. Pure-Python
tests and static XML kinematics preflight passed, but full simulation,
physics, collisions at all new placements, and actual MP4 playback need
to be verified on your machine. Default grip uses SCRIPTED attachment.

See README.md for the simulation semantics, exact seed behavior, and
troubleshooting.
